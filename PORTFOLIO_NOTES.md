The README explicitly identifies this repository as a fork of Nummer/Destroy-WIndows-10-Spying. Treat the utility as upstream code unless a personal delta is demonstrated.

## 10 tasks
1. Record the exact upstream baseline and fork date.
2. Isolate personally authored commits/files from the upstream codebase.
3. Preserve Nummer/upstream attribution and Apache 2.0 licensing.
4. Document exactly which binaries, images and references were removed or changed in this fork.
5. Reassess every system modification against currently supported Windows versions before recommending execution.
6. Add dry-run/report-only behavior before any destructive system changes if the fork is ever maintained.
7. Require explicit confirmation and rollback documentation for service/app/telemetry modifications.
8. Avoid broad claims such as “remove all spyware” unless each action is currently verified and narrowly described.
9. Do not present this fork as an original security/privacy product in portfolio materials.
10. Archive/unpin it unless the personal code-review or hardening delta is substantial and documented.
